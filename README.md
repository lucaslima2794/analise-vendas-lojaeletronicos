# Análise de Vendas

Projeto treino de análise de dados ponta a ponta: extração e tratamento de uma base de vendas, análise exploratória com tabela dinâmica no Excel, e construção de um dashboard interativo no Power BI para responder perguntas de negócio.

## Objetivo

Responder, a partir de uma base de vendas com mais de 700 registros, perguntas como:
- Qual categoria de produto gerou o maior valor de venda?
- Qual região teve o maior lucro acumulado?
- Qual canal de venda teve a maior quantidade de itens vendidos?
- Como o valor de venda evoluiu ano a ano?
- Quais são os 5 produtos com maior lucro total?

## Ferramentas utilizadas

- **Excel** — tratamento dos dados e análise exploratória via tabela dinâmica
- **Power BI** — construção do dashboard interativo

## Processo

1. **Extração e organização dos dados** — base bruta de vendas (produto, canal, região, custo, lucro, data).
2. **Análise exploratória** — tabela dinâmica no Excel para responder as 5 perguntas de negócio antes de partir para a visualização.
3. **Dashboard** — tradução das respostas em visualizações no Power BI, com KPIs de receita e lucro, distribuição por categoria, canal e região, e evolução anual das vendas.
   

## Principais insights

- A categoria **Computers** foi a que mais gerou receita, seguida por **Cameras and camcorders**.
- **North America** concentra a maior parte do lucro total entre as regiões analisadas.
- O canal **Store** é responsável pela maior quantidade de itens vendidos, muito à frente de Online, Reseller e Catalog.
- Os produtos mais lucrativos não são necessariamente os mais vendidos — os projetores lideram o Top 5 de lucro mesmo sem ser a categoria líder em receita.
